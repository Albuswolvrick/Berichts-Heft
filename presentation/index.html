Über das Projekt

Modern, Intuitiv & Barrierefrei

Das Berichts-Heft ist eine umfassende digitale Plattform, die entwickelt wurde, um den Prozess der Ausbildungsdokumentation für Auszubildende und Ausbilder grundlegend zu modernisieren. Weg von lästigem Papierkram, hin zu einem schlanken, effizienten und digitalen Workflow.

Mit Funktionen wie der automatisierten Erstellung von Tages-, Wochen-, Monats- und Jahresberichten, nahtloser Statusverfolgung und integrierten administrativen Kontrollen bietet es eine robuste Infrastruktur für die Verwaltung von Ausbildungszielen.

Besonderer Fokus auf Barrierefreiheit: Die Anwendung ist vollständig auf die Bedürfnisse der Nutzer anpassbar. Ein integrierter Schieberegler ermöglicht es, die Textgröße dynamisch zu verändern. Zudem unterstützt die App nahtlose Wechsel zwischen Hell-, Dunkel- und Doom-Modus.

  • ✓ Dynamische Textgrößenanpassung (Barrierefreiheit)
  • ✓ Automatisierte Berichtsverwaltung (Tages-, Wochen-, Monatsberichte)
  • ✓ Mehrsprachigkeit (über 10 Sprachen inkl. Piratisch!)
  • ✓ Heller, Dunkler und Doom-Modus

reportController.js (Status Updates)

/**
 * Automatische Bereinigung abgelehnter Berichte
 * und Status-Updates in Echtzeit.
 */
const updateReportStatus = async (req, res) => {
    const { id } = req.params;
    const { status } = req.body;

    try {
        if (status === 'REJECTED') {
            await database.reports.delete({ where: { id } });
            return res.status(200).json({ 
                message: 'Bericht abgelehnt und gelöscht.' 
            });
        }

        const updatedReport = await database.reports.update({
            where: { id },
            data: { status }
        });

        res.status(200).json(updatedReport);
    } catch (error) {
        res.status(500).json({ error: 'Interner Serverfehler' });
    }
};
accessibility.js (Dynamische Textgröße)

/**
 * Barrierefreiheit: Dynamische Anpassung der Textgröße
 * im gesamten Dokument über CSS Variablen.
 */
const textSizeSlider = document.getElementById('textSizeSlider');
const rootElement = document.documentElement;

// Lade gespeicherte Textgröße
const savedSize = localStorage.getItem('textSize') || '16';
rootElement.style.setProperty('--base-font-size', `${savedSize}px`);
textSizeSlider.value = savedSize;

// Event Listener für Echtzeit-Änderung
textSizeSlider.addEventListener('input', (e) => {
    const newSize = e.target.value;
    rootElement.style.setProperty('--base-font-size', `${newSize}px`);
    localStorage.setItem('textSize', newSize);
});
